# Decathlon: подготовка к защите

Сайт-шпаргалка: слайды, матрицы, цифры и термины.

Как выложить на GitHub Pages:
1. Создать репозиторий на github.com, нажать Add file, Upload files, перетащить всё содержимое этой папки (index.html, slides.html, matrices.html, numbers.html и папку img).
2. Settings, Pages, Source: Deploy from a branch, Branch: main, папка / (root), Save.
3. Через минуту сайт откроется по адресу https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/
